pdf

A pane for the SolidOS data browser that shows PDF documents in the browser’s own viewer. A title bar gives the file name, size and number of pages, with Open and Download buttons. It is one module, loaded by link.

Try it

  • Solid panes (3 pages) Pane runner SolidOS

The page asks before it runs a pane from a site it has not seen. Allow it, and the document opens.

Early days: where the browser has no PDF viewer (most phones), the pane gives the link to open the file instead.

The pane: https://solid-panes.github.io/pdf/pdf-pane.js
