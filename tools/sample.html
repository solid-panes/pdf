Solid panes

One file, loaded by link. A sample document for the PDF pane.

What a pane is

A pane is a small JavaScript module that draws one kind of resource in the SolidOS data browser. When you open a resource, the browser asks each pane it knows whether it can show it, and draws it with the one that says yes.

A pane needs no build step and no release. It is a single file on any web server, and the browser loads it at runtime from its address.

Loading a pane by link

Add the pane's address to the browser's own link with ?pane=, and the resource with &uri=. The page asks before it runs a pane from a site it has not seen.

https://solidos.org/docs/browser/?pane=<pane url>&uri=<resource url>

The contract

Four parts, all optional but one.

PartWhat it does
nameA unique name. A second pane with the same name is ignored.
iconA small picture, usually a data: address so the pane stays one file.
label()Returns a short tab name if the pane fits the resource, or nothing.
render()Returns one element that shows the resource. It may fill it in later.

House rules

Build the page with plain elements and text, never raw markup, because a document can carry hostile text. Keep the styles in the file. Make it work on a phone. A pane that only reads never writes.

Why it matters

New views ship when they are ready.

Because a pane is loaded by link, a new view for videos, sound, pictures or documents can be tried by anyone, today, on any SolidOS page. When it is good, a server can load it for everyone with one flag, and nothing else has to change.
